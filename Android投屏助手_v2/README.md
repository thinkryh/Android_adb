# Android 投屏助手 v2（WPF 图形版）

v2 是项目的图形界面版本，保留仓库中的 scrcpy 和 ADB。当前源码具有设备列表、USB／IP 连接、配对码、扫码入口、mDNS 发现、多设备独立投屏、深浅玻璃主题以及投屏快捷栏；完整安装包分发和跨机型验收仍未完成。

从仓库根目录双击 `Android投屏助手.bat` 启动本机发布程序。**不要用本目录的 `Android投屏助手_v2.bat` 判断最新版本是否存在**：它尚未搜索 `glass-v13`。从源码构建需要 .NET 10 SDK；目前生成的 v2 发布程序依赖目标电脑安装 .NET 10 Desktop Runtime，且必须和 `scrcpy/` 依赖目录一同分发。

快捷栏包括收起／展开、置顶、主页、返回、最近任务、截图和录屏。左键截图优先保存当前投屏窗口画面，右键保存手机原画；截图和录屏都在当前用户的“图片\Android投屏助手”。单段录屏上限 180 秒。黑夜模式默认启用，可在主界面切换浅色模式。
