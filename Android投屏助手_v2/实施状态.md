# v2 实施状态

## 已完成并通过自动验证

- WPF 项目和 MVVM 基础结构。
- 真实读取 adb devices -l，识别 USB、IP 无线、mDNS 服务、模拟器和未授权状态。
- 多设备卡片列表和自动刷新。
- USB 设备独立启动 scrcpy。
- IP 直连和配对码配对。
- adb mDNS 服务发现。
- Android 11 无线调试二维码生成、配对服务等待和关闭取消。
- 无线默认均衡参数：1600 像素、12 Mbps、30 帧、30ms 缓冲。
- 每台设备独立 scrcpy 进程，避免多设备互相操作。
- 投屏快捷工具栏：主页、返回、最近任务、截图、全屏、息屏、录屏。
- 工具栏可通过顶部手柄拖动，并根据拖动方向吸附到投屏窗口左侧或右侧；投屏窗口移动时自动跟随。
- 主窗口和工具栏关闭透明窗口渲染，启用布局取整、像素对齐和 ClearType，改善高 DPI 下的文字清晰度。
- 截图保存到当前用户图片目录下的 Android投屏助手 文件夹。
- 录屏使用 Android 自带 screenrecord，结束后拉回“视频\\Android投屏助手”目录。
- WPF 卡片、圆角、阴影和悬浮工具栏样式。
- 根目录批处理优先启动 v2，找不到 v2 发布程序时回退到 v1。
- 真实构建和发布通过，0 个编译警告、0 个编译错误。
- 发布目录包含图形程序、scrcpy.exe 和 adb.exe。
- 源码扫描未发现真实手机 IP、配对码或本机绝对路径。
