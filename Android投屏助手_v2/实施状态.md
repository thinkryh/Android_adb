# v2 实施状态

更新时间：2026-09-25。以下区分“代码已具备”和“实机已验收”，不把源码提交或本机发布目录误写成 GitHub 已提供完整可执行安装包。

## 代码已具备

- WPF 主界面与真实 ADB 设备列表；USB、IP 直连、六位配对码、二维码配对入口、mDNS 发现和最近无线地址重试。
- 每个 ADB 序列号独立的 scrcpy 会话；USB 为 1920／16 Mbps／30 帧，无线为 1600／12 Mbps／30 帧／30 ms 缓冲。
- 与投屏窗口关联的快捷栏：置顶、主页、返回、最近任务、快速／原画截图、录屏、吸附／自由拖动、收起／展开。
- 深浅两套 WPF 玻璃样式，默认黑夜模式；主题切换同步作用于快捷栏及弹窗。
- 截图和录屏统一写入当前用户“图片\Android投屏助手”；录屏单段最多 180 秒，导出后检查 MP4 文件索引。
- 主界面退出确认、受管投屏与快捷栏关闭；本机根 BAT 优先搜索 `glass-v13`，找不到 v2 时退回 v1。

## 已有证据与待验收

- 本机有 `glass-v13` 发布目录，EXE 和打包的 scrcpy／ADB 文件齐全；此前有真实 USB 投屏、截图和录屏相关验证，以及工具栏收起状态的隔离验证。
- v2 无线各入口、多手机同时投屏、同机 USB／Wi-Fi 双通道身份处理、混合 DPI／多屏的吸附层级，以及不同厂商录屏与 180 秒到时导出尚未完成覆盖测试。
- `bin/`、`obj/` 被 Git 忽略。克隆仓库后须构建，或另取完整发布包；不能只复制主程序 EXE。
