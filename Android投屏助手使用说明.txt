Android 投屏助手｜简明使用说明

1. 保持整个工具文件夹完整，不要只复制 .bat 或 .exe。
2. 手机开启开发者选项和 USB 调试，连接数据线后在手机上允许授权。
3. 双击文件夹根目录的“Android投屏助手.bat”。本机有 v2 发布程序时进入图形界面；没有时进入 v1 提示窗口。
4. 在 v2 设备列表中选择手机并点击“开始投屏”。结束某台手机的投屏可关闭它的画面窗口，或在主界面点击“结束”；关闭 v2 主界面会确认退出并结束受管投屏。

Android 11 及以上的无线调试：
- 手机和电脑连接到可互通的同一网络，在手机“开发者选项 → 无线调试”中开启无线调试。
- 配对码方式：选择“使用配对码配对设备”，把临时配对地址及六位配对码填入助手；连接地址要取无线调试主页面，端口可能与配对端口不同。
- 也可在 v2 尝试扫码、IP 直连或 mDNS 发现；发现失败时优先核对手机授权、地址／端口和网络。

快捷栏左键截图为较快的投屏窗口图，右键截图为较慢的手机原画图。截图和录屏保存在当前用户“图片\Android投屏助手”；单段录屏最长 180 秒。主题默认黑夜模式，可在主界面切换。

工具自带 scrcpy 与 ADB，无需另行安装这两个投屏组件。v2 目前依赖目标电脑安装 .NET 10 Desktop Runtime；只有仓库源码而没有本地发布文件时，须先构建 v2。更多信息见 README.md 和 docs 文件夹。
