# Android 投屏助手

一个适用于 Windows 的 Android 手机投屏小工具，内置 scrcpy 与 ADB，无需额外安装投屏组件。

## 功能

- 优先使用数据线连接，连接稳定、延迟低。
- 没有可用数据线连接时，支持 Android 11 及以上的无线调试。
- 自动记住上一次成功的无线连接地址，后续可直接复用。
- 无线模式默认使用均衡画质：1600 像素、12 Mbps、30 帧、30ms 缓冲。
- 有线模式使用清晰画质：1920 像素、16 Mbps、30 帧。
- 支持中文输入（电脑端输入法与手机端输入框配合使用）。
- 投屏窗口标题为“Android投屏助手”。

## 使用条件

- Windows 10 或 Windows 11。
- 手机开启 USB 调试，或手机与电脑连接到同一个无线网络并开启无线调试。
- 工具目录中的文件需要保持相对位置，不要单独移动 `程序组件` 或 `scrcpy` 文件夹。

## 启动方式

双击运行：

```text
Android投屏助手.bat
```

程序会先检查数据线连接：

1. 如果检测到数据线设备，自动使用有线投屏。
2. 如果没有检测到数据线设备，但已经连接过无线设备，自动尝试上次的无线地址。
3. 如果上次地址不可用，按照窗口提示完成无线调试配对和连接。

## Android 11 无线调试

在手机中打开：

```text
设置 → 更多设置 → 开发者选项 → 无线调试
```

首次使用时选择“使用配对码配对设备”，输入手机显示的配对地址和六位配对码。完成配对后，再输入无线调试主页面显示的连接地址。

配对端口每次可能变化；连接端口通常相对稳定。手机和电脑必须连接同一个无线网络。

## 关闭方式

关闭投屏窗口即可结束投屏。提示窗口可以单独关闭，不会影响已经启动的投屏窗口。

## 目录说明

```text
Android投屏助手_v1/
├─ Android投屏助手.bat
├─ Android投屏助手使用说明.txt
├─ 程序组件/
│  └─ Android投屏助手.ps1
└─ scrcpy/
```

运行过程中生成的本地连接记录和配置不会作为项目文件提交。

## v2 图形界面预览

仓库内的 Android投屏助手_v2 目录正在开发 WPF 图形版本，保留现有 scrcpy 和 adb，增加真实设备列表、USB/无线连接、多设备投屏、mDNS 和二维码配对入口，以及投屏快捷工具栏。

v1 的批处理和 PowerShell 流程仍然保留，可作为回退方案。v2 需要 .NET SDK 构建，完成构建后根目录的 Android投屏助手.bat 会优先启动图形程序。

本项目脚本用于启动和配置投屏流程。`scrcpy` 与 `adb` 属于第三方组件，请遵循其各自的开源许可证和版权声明。
