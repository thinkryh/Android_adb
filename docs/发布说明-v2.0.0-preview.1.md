# v2.0.0-preview.1 发布说明

这是 Windows x64 图形界面预览版，保留现有 scrcpy 和 ADB。主界面提供 USB、IP 直连、配对码、扫码配对和 mDNS 入口；有线设备优先，只有一台已授权设备时自动投屏。设备列表在单设备时占满一行，多设备时每行两张卡片。无线画质默认均衡，快捷栏提供常用控制、截图和录屏。

## 安装

1. 在 Windows 10／11 x64 上安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。这是依赖框架的构建，ZIP 中不包含 .NET 运行时。
2. 下载并完整解压 `Android投屏助手-v2.0.0-preview.1-win-x64.zip`，不要单独提取 EXE。
3. 运行解压目录内的 `Android投屏助手.exe`。USB 使用前在手机上开启调试并授权；无线使用前确保电脑和手机网络互通。

## 验证边界

- 已完成 Windows x64 Release 编译与发布目录检查；EXE 为 x64，包含 scrcpy、ADB、QRCoder 和许可声明。
- 在当前 Windows 电脑连接一台 Android 11 手机时，已实际启动图形程序、识别有线设备、自动打开投屏窗口和快捷栏；退出时对应窗口和进程结束。
- 无线配对、二维码、mDNS 和多设备同时投屏尚未在不同网络及多台实体设备上全面实测；本版本作为预览版供测试反馈。
