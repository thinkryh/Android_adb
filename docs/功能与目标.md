# 功能与目标

更新时间：2026-09-26。本文描述 v2 源码当前实现；源码、构建输出和发布包的区别见[文件状态](文件状态.md)。

## 产品目标

让普通 Windows 用户通过清晰的图形界面完成 Android 设备发现、连接、投屏及常用控制；保留 scrcpy 的低延迟投屏和 ADB 的设备能力。连接失败时，用户应能知道卡在授权、配对、连接、投屏启动还是文件导出。多设备操作必须明确对应的目标设备，避免误操作另一台手机。

首版聚焦投屏：可发现并管理多台设备，支持 USB、IP 直连、配对码、扫码和 mDNS，提供默认均衡的无线画质，以及一套与投屏窗口关联的快捷栏。视觉目标是统一的圆角、半透明、高光玻璃感，默认黑夜模式，同时保持文字清晰、按钮对齐和可读性。

## 当前功能

| 场景 | 当前行为 | 注意点 |
| --- | --- | --- |
| 设备列表 | 读取 `adb devices -l`，每行两张卡片显示 USB、IP 无线、mDNS、模拟器及在线／未授权／离线状态；约每 5 秒刷新 | 同一手机的 USB 与 Wi-Fi 序列号目前会作为两个条目显示，不做物理身份合并 |
| USB 投屏 | 首次打开时恰好只有一台已授权设备，自动启动其 scrcpy；否则由用户选择；有线参数为最长边 1920、16 Mbps、30 帧 | 自动启动只执行一次，不在后续定时刷新或新增设备时触发；v2 不是 v1 的自动 USB 优先流程 |
| 无线投屏 | 支持直接输入连接地址；设备列表为空时尝试最近保存的至多 4 个地址；无线最长边 1600、12 Mbps、30 帧、30 ms 视频缓冲 | 自动重连只在列表为空时触发；它不是后台持续重连服务 |
| 配对码 | 输入手机“使用配对码配对设备”页面的配对地址与六位码；可另填无线调试主页面的连接地址 | 配对地址和连接地址是两个不同端口；只配对、不填连接地址时仍需后续连接 |
| 扫码 | 生成 Android 无线调试二维码，等待配对服务，完成配对后寻找连接服务 | 依赖 Android 11+、ADB mDNS 和局域网发现；不同厂商系统仍需真机验证 |
| mDNS | 列出可连接的无线服务，由用户选择 | 发现为空时可改用 IP 直连或配对码 |
| 多设备 | 按 ADB 序列号维护独立 scrcpy 进程与快捷栏，可分别开始或结束投屏 | 两台以上同时投屏尚缺完整真机验收 |
| 快捷栏 | 与对应投屏窗口关联；可置顶、主页、返回、最近任务、截图、录屏；靠近左右边缘时吸附，也可拖离自由放置；可收起为小入口 | 收起／展开的窗口尺寸状态已有隔离测试，移动、层级和多屏交互还需人工验收 |
| 截图 | 左键优先抓取当前投屏窗口画面；失败时回退 ADB 原画截图；右键直接保存 ADB 原画 | 快速截图分辨率取决于投屏窗口，原画截图速度取决于 ADB／设备 |
| 录屏 | Android `screenrecord` 录制，停止后从手机拉取并校验 MP4 索引；单段上限 180 秒 | 自动到时尝试导出；设备命令、存储权限和不同厂商实现尚需覆盖测试 |
| 主题 | 默认黑夜模式，主界面可切换浅色模式，快捷栏及弹窗跟随 | 主题选择记录在本机用户目录；是 WPF 视觉模拟，不是系统原生折射效果 |
| 退出 | 关闭主界面会确认，并尝试保存录屏、关闭快捷栏和所有受管投屏；关闭单个投屏窗口会关闭对应快捷栏 | 不提供“关闭主界面后继续投屏”的 v2 驻留模式；v1 的提示窗口行为不同 |

## 交互与验收目标

1. 首次启动能显示真实设备及其状态。只有一台已授权设备时自动投屏；零台、多台、未授权或离线时不自动投屏。连接地址格式错误应直接给出中文提示。
2. 配对与连接分两步：配对成功不等于投屏成功。手机的配对端口可能变化，连接端口应以手机无线调试主页面为准。
3. 同时连接多台设备时，开始／结束、导航、截图与录屏只作用于被选中的那台设备。USB 和 Wi-Fi 双通道的设备身份需要后续规则设计，不能仅靠当前序列号推断同一手机。
4. 工具栏吸附后应随对应投屏窗口移动、层级变化及最小化；解除吸附后可自由拖动；收起状态仍应附着，展开不应遗失按钮或录屏状态。
5. 截图成功以目标 PNG 实际存在且可打开为准；录屏成功以本机 MP4 存在、非空且包含 `ftyp`、`moov` 为准，不能仅凭“录制成功”提示。
6. 关闭主界面时，受管投屏进程与快捷栏不应残留；录制中的文件先尝试保存，失败必须提示并保留手机原文件供重试。

## 范围与非目标

- 保留现有 scrcpy 和 ADB，不自研视频解码／投屏协议；现阶段不引入文件管理、APK 管理、AI、脚本自动化或 HTTP API。
- 当前默认画质固定，无线为均衡；不在启动过程中反复弹出画质菜单，也不静默降低到更低画质。
- 以 Windows 10／11 和 Android USB 调试为基本环境；扫码及 Android 系统的无线调试配对流程面向 Android 11 及以上。Android 9 等旧版设备可能借助 USB 执行传统 `adb tcpip`，当前 v2 不提供该专门向导。
- v2 目前没有系统托盘驻留；关闭主界面就是退出受管会话。
