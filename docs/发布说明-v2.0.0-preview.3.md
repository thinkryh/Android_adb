# Android 投屏助手 v2.0.0-preview.3

本版更新 Windows x64 图形界面的启动页。单设备窗口采用 608×467 的竖向轻窗布局；多设备时窗口扩宽，设备卡仍每行两张。“无线连接”位于标题栏“刷新”左侧，展开后可选择 IP 直连、配对码、扫码配对或 mDNS 发现。设备卡中的 USB／无线连接状态改为文字提示，深浅色切换改为右下角的小图标按钮。

## 下载与运行

1. 在 Windows 10／11 x64 上安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。本包不内置 .NET 运行时。
2. 下载并完整解压 `AndroidScreenAssistant-v2.0.0-preview.3-win-x64.zip`，运行其中的 `Android投屏助手.exe`。请保留同目录的 DLL、`scrcpy/` 和许可文件。
3. USB 调试须在手机上授权；无线调试要求手机和电脑网络互通。手机只有一台且已授权时，助手会自动投屏。

应用 ZIP 的 SHA-256：`13407c6d5b3a98bae72226a22c283ef9d5563a552a5c56eb273cfe0409762759`。Release 同时附有 `SHA256SUMS.txt`，列出应用包及三个上游源码附件的哈希。

## 验证范围

- Release x64 构建成功。应用 ZIP 含 31 个文件；解压后逐一比对哈希一致，EXE 的 PE 架构为 x64，运行配置依赖 .NET 10 Desktop Runtime。
- 在当前 Windows 电脑上从**解压后的 ZIP 目录**运行，使用一台 Android 11 USB 手机验证了设备识别、自动投屏、结束投屏及退出。另在同版程序中验证了无线菜单的 IP 入口弹窗和深浅色切换。
- 零设备、多设备同时投屏、配对码／扫码／mDNS 的完整无线流程，以及未安装 .NET 运行时的目标电脑，尚未实测。此版继续标为预览版。
