# 投屏助手 v2.0.0-preview.5（Windows x64）

本版仅面向 Android 设备。浅色太阳和深色月亮图标统一为 10px，主题切换入口移除按钮底板。修正快捷栏展开／收起箭头受默认右边距影响而偏左的问题，统一箭头位置，保留收起后的圆角玻璃底板。清理本机废弃接收器测试工程、原生依赖与旧构建，并更新 Android 功能范围及交接说明。

## 下载与运行

1. 安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。发布包不内置运行时。
2. 完整解压 `AndroidScreenAssistant-v2.0.0-preview.5-win-x64.zip`，双击其中的 `Android投屏助手.exe`；保留全部 DLL、`scrcpy/` 和许可文件。
3. Android 手机开启 USB 调试并授权电脑；无线连接使用 IP 直连或 Android 11 及以上的配对码流程。手机和电脑网络需互通。

本 Release 同时提供 `SHA256SUMS.txt`，用于核对应用 ZIP 与三个上游源码附件。

## 验证范围

- Windows x64 Release 构建通过；核对发布包架构、运行时依赖、文件完整性及 SHA-256。
- WPF 离屏渲染检查展开／收起按钮与置顶按钮的尺寸、横向位置，以及切换前后的顶部位置；两种主题均通过界面渲染。
- 本地源码、构建及发布目录复查未发现废弃接收器功能引用和原生依赖。
- 本次未重新进行 Android 真机投屏、无线配对、多设备并行及截图／录屏验收，继续作为预览版发布。离屏预览使用模拟设备，不能替代真机测试。
