# 架构与约束

更新时间：2026-09-26。路径均相对于项目根目录 `Android投屏助手_v1/`。

## 运行链路

```text
Android投屏助手.bat
  ├─ 找到本地 v2 发布程序 → Android投屏助手_v2/.../Android投屏助手.exe
  │    ├─ ADB：设备枚举、连接／配对、按设备发送按键、截图、录屏
  │    ├─ scrcpy：每个 ADB 序列号启动一个投屏进程
  │    └─ WPF：主界面、玻璃弹窗、每个投屏窗口对应的快捷栏
  └─ 未找到任何 v2 程序 → 程序组件/Android投屏助手.ps1（v1）
```

根目录 BAT 优先查找根目录 `发布版/`，其次使用 Release 构建输出；v2 目录里的 BAT 也调用这个统一入口。v2 首次打开时仅在恰好一台已授权设备的情况下自动投屏，其余情况按设备手动选择；v1 PowerShell 脚本才实行 USB 优先、无 USB 后尝试无线的自动流程。

## 设备与连接约束

- 设备必须在手机上开启开发者选项、USB 调试，并同意本机授权。无线调试要求手机与电脑位于可互通的网络，且 Android 11+ 才有当前图形版的配对／扫码使用路径。
- 连接地址格式为 `IP:端口`。配对地址使用手机“配对码配对设备”页面的临时端口；连接地址使用无线调试主页面的端口。可成功配对却不能连接，不能把两个地址混用。
- v2 用 `adb devices -l` 返回的序列号区分会话；同一部手机的 USB 与无线通道可能显示为两条记录。真实双设备和双通道切换仍待验证。
- v2 自动重试最多四个已保存地址，且仅当刷新后没有任何列表项时执行。地址保存在 `%LOCALAPPDATA%\Android投屏助手\settings.json`，最多保留 12 个；可能包含私有 IP 和端口，发布日志、截图或 GitHub 内容须脱敏。本机配置无须为了展示而脱敏。
- `adb` 的配对凭据由 ADB 自己管理，不由本项目的 `settings.json` 保存六位配对码；二维码密码仅在本次窗口流程中生成使用。

## 画面、媒体与进程约束

- 有线最长边 1920、16 Mbps、30 帧；无线最长边 1600、12 Mbps、30 帧、30 ms 视频缓冲。两者使用 H.264、`--stay-awake`、`--keep-active`、`--keyboard=uhid`。实际帧率、清晰度及延迟还受手机编码器、USB／Wi-Fi 与电脑性能影响。
- `--keyboard=uhid` 下中文输入需结合手机输入法或剪贴板粘贴；不能保证电脑输入法的每个组合键都直接映射到手机。
- 左键快速截图抓取的是当前 scrcpy 客户区，清晰度跟投屏窗口大小有关；投屏窗口最小化、不可见或驱动不支持 `PrintWindow` 时会退回 ADB。右键截图固定走手机 `screencap -p` 原画路径。
- 截图 PNG 和录屏 MP4 都写入当前用户“图片\Android投屏助手”。录屏先写手机 `/sdcard/` 临时文件，结束后拉到电脑并检查 MP4 完整索引；导出失败时优先保留手机端文件。单段最长 180 秒，不能传 360 秒给 Android `screenrecord`。
- 主程序通过互斥量限制同一类型的重复启动。每台设备一个受管 scrcpy 进程，快捷栏作为对应 scrcpy 窗口的 owned window；关闭主程序会确认后结束所有受管投屏。系统任务管理器仍可能显示独立的 `scrcpy.exe` 和 `adb.exe` 进程，这是实际运行结构。
- 快捷栏靠近投屏窗口边缘吸附，收起后为 36 像素宽入口，展开宽度 60 像素。WinEvent 跟踪窗口移动／最小化，定时器兜底；多屏、混合 DPI 与其他窗口层级仍需真实桌面验证。

## 构建、分发与依赖

v2 项目为 `net10.0-windows` WPF，依赖 QRCoder 1.6.0。构建机需要 .NET 10 SDK 和还原依赖所需的包源；当前发布配置为 `SelfContained=false`、`PublishSingleFile=false`，使用者需要安装 .NET 10 Desktop Runtime。输出目录中的 EXE、DLL、runtimeconfig 和整个 `scrcpy/` 要一起复制；只发 `.bat` 或 `.exe` 不足以运行。

```powershell
dotnet restore .\Android投屏助手_v2\Android投屏助手.csproj
dotnet build .\Android投屏助手_v2\Android投屏助手.csproj -c Release
dotnet publish .\Android投屏助手_v2\Android投屏助手.csproj -c Release --self-contained false -o .\发布版
```

本机 `发布版/` 包含程序、`scrcpy/` 依赖和许可声明，共 25 个文件，约 25.66 MiB／26.91 MB；主程序 EXE 为 211,968 字节。该数字不是自包含包或压缩包大小，且会随构建变化。`发布版/`、`bin/`、`obj/` 被 `.gitignore` 忽略，GitHub 克隆者需自己构建或另行下载发布包。批处理文件必须保持 CRLF 换行，仓库用 `.gitattributes` 固定此规则。
