# v2.0.0-preview.2 发布说明

这是 `v2.0.0-preview.1` 的第三方许可材料修正版。应用程序、scrcpy、ADB 和 QRCoder 的可执行文件未改变；补齐 dav1d、Android Platform-Tools 和 zlib 的许可／通知文本，记录 FFmpeg DLL 的实际构建参数，并在同一 Release 提供 FFmpeg、libusb、dav1d 的对应上游源码包。旧版应用 ZIP 缺少部分材料，建议改用此版本。

## 安装

1. 在 Windows 10／11 x64 上安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。此包不内置 .NET 运行时。
2. 下载并完整解压 `AndroidScreenAssistant-v2.0.0-preview.2-win-x64.zip`；运行其中的 `Android投屏助手.exe`，不要只提取 EXE。
3. USB 投屏需要开启手机调试并授权；无线连接需要手机与电脑网络互通。

应用 ZIP 的 SHA-256：`191f4d65724e3a61a809a24f4e4d462c86197b694687cbf23ebb825671391316`。

## 验证与许可边界

- `v2.0.0-preview.1` 在当前 Windows 电脑连接一台 Android 11 手机时，实际完成了启动、USB 识别、自动打开投屏窗口及退出进程的验证。此版只更新随包文本，重新核对了可执行文件一致性和 ZIP 完整性。
- 无线配对、二维码、mDNS 和多设备同时投屏仍未在不同网络及多台实体设备上全面实测。
- 本项目源码按 MIT 许可；scrcpy、FFmpeg、libusb、dav1d、ADB、SDL、QRCoder 等保持各自许可。完整清单见 [第三方组件与许可](../THIRD_PARTY_NOTICES.md)，对应源码与哈希见 [源码附件清单](../third_party_licenses/SOURCE_ARCHIVES.md)。
- FFmpeg DLL 采用 LGPL 配置，保留原名并动态链接。本软件使用 FFmpeg 项目的库，采用 LGPL 2.1 或更高版本；[FFmpeg 对应源码](https://github.com/thinkryh/Android_adb/releases/download/v2.0.0-preview.2/ffmpeg-8.1.2.tar.xz)随本版提供。程序内署名、Google 官方预编译 ADB 的再分发边界、图标素材权利仍需进一步确认，因此不宣称第三方许可认证完成。
