# 投屏助手 v2.0.0-preview.4（Windows x64）

本版将图形版源码集中到 `src/`，旧脚本归入 `legacy-v1/`。启动页缩为 520×467；设备每行最多两张卡片，无线菜单保留 IP 直连和配对码，并在弹窗说明手机操作路径及配对、连接端口的区别。深浅主题按钮位于右下角。

投屏快捷栏展开和收起时均宽 48px，顶部切换按钮与置顶按钮同为 38×38px；展开后仍可拖动。截图保留快速窗口截图与手机原画两种方式。录屏改为电脑端捕获投屏窗口，快捷栏显示已录时长，停止后直接保存到“图片\Android投屏助手”；目前不录声音。主窗口已取消系统调整大小边框并设置 Windows DWM 不绘制边框，实际桌面外观仍需更多机器验证。

## 下载与运行

1. 安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。发布包不内置该运行时。
2. 完整解压 `AndroidScreenAssistant-v2.0.0-preview.4-win-x64.zip`，运行其中的 `Android投屏助手.exe`。请保留同目录的 DLL、`scrcpy/` 文件夹、许可证与第三方声明。
3. 手机开启 USB 调试并授权电脑。无线调试需手机和电脑网络互通；Android 11 及以上可使用手机显示的配对地址与六位配对码。

应用 ZIP 的 SHA-256 为 `b37dc8c89105f2c7196d5a77222f6a42119257b4e7a1e7611193bf8f5533a6e4`。下载后可用同版附件 `SHA256SUMS.txt` 核对应用 ZIP 和三个上游源码附件。

## 已验证与尚待验证

- Windows x64 Release 编译通过，0 个警告、0 个错误；应用 ZIP 含 33 个文件，解压后逐一比对哈希一致，EXE 的 PE 架构为 x64，运行配置依赖 .NET 10 Desktop Runtime。
- 本机从解压目录运行，检测到一台已授权 USB 设备并自动打开 scrcpy；进程响应正常。在真实投屏窗口录制约 2.5 秒，生成 54,758 字节 MP4，已检查 `ftyp`、`mdat`、`moov` 和本地落盘。视频内容和不同设备上的画质尚需人工查看。
- 离屏 WPF 检查确认工具栏宽度、展开／收起按钮与置顶按钮尺寸、顶部位置一致。Windows 11 上设置 DWM 无边框属性的系统调用返回成功；真实窗口顶部是否完全无白边仍需目测。
- 无线配对、IP 连接、多设备并行、不同缩放和显卡环境、目标电脑运行时安装体验尚未在本版全面实测，因此继续标为预览版。
